# Card pictures

Put one picture per card in this folder and use its file name as `image` in `cards.lua` (for example `evo001.png`).

- PNG, JPG or WebP. About 700 × 500 pixels (landscape, 7:5) fills the picture window. It is cropped to fit, so keep faces near the middle.
- Cards without a picture show a placeholder with the person's initials.
- No restart of the whole server is needed. `restart vr-cards` picks up new pictures.
